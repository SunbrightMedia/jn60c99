# b36 — half-rate reverb FIXED with real anti-alias/anti-image FIRs (2026-08-28)

b35 built a half-rate reverb that ALIASED (the user's ear caught ~30 dB of grit
in the tail; the difference spectrum confirmed it). b36 fixes it properly.

## The fix
A 41-tap linear-phase FIR (`eb_reverb_halfband.h`, generated by
`tools/engineb/gen_reverb_halfband.py`), cutoff 8 kHz, used BOTH ways:
- **decimation in**: low-pass the mono send, then drop 2:1. Kills the fold band.
- **interpolation out**: zero-stuff the half-rate wet 1:2, then the same FIR
  (polyphase, implicit x2) reconstructs full rate. Kills the images.

MEASURED filter: passband ripple <= 0.344 dB to 6 kHz; fold band (>= 11025 Hz)
>= 53 dB down, so the worst alias is ~ -53 dBFS. The dry main signal is still
kept FULL rate (mono tank drive, dry stripped and re-added), so only the wet
tail is touched.

## Proof the aliasing is gone (difference spectrum, the metric that caught it)
`long_LFO+tail`, reverb tail band energy:
| band | ref (full-rate fork) | b35 (broken) | b36 (fixed) |
|---|---|---|---|
| 5–11 kHz  | −64.5 dB | −41.3 dB (+23) | −64.5 dB (match) |
| 11–16 kHz | −76.4 dB | −37.1 dB (+39) | −76.3 dB (match) |
`chorus pad`: every band within 0.1 dB of the reference.

## The remaining trade (deliberate, for the ear at F2)
Third-octave worst-band difference, fixed half vs full-rate fork:
- musical patches (chorus pad, delay keys, pluck): 1.0–2.6 dB.
- DCO torture scenarios (neg-wrap, neg-pitch-sweep): up to 12.9 dB at ~13 kHz —
  the wet reverb air above 8 kHz is removed. Not musical patches.
The trade is now "a slightly darker reverb tail," NOT grit.

## Proven
- OFF path: `null_b --module reverb` residual EXACTLY 0 (flag-guarded edits).
- Filter measured (gen_reverb_halfband.py --measure).

## OPEN — cost, and whether the trade is worth it
The FIR is not free (~decim + 2x interp per sample), so the net headroom saving
on silicon is SMALLER than b34's filterless probe. Two open questions for the
user / the board:
1. Does the darker tail (8 kHz) sound acceptable? (renders sent for F2.)
2. Does the net saving, AFTER the FIR cost, still cover the type-5 patches? —
   a silicon measurement, not yet taken.
The cutoff (8 kHz) trades air for anti-alias margin; it can be raised toward
~9.5 kHz at a higher tap cost if the user wants more air.
